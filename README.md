🧠 Neural Network Notebooks

This repository contains lab assignments and practice notebooks from the Neural Networks course.
Each notebook focuses on implementing neural network concepts from scratch to clearly understand the underlying logic and learning process.

The repository will be updated weekly with new lab assignments based on classroom demonstrations and instructions.

🚀 How to Run

Clone the repository:

git clone https://github.com/nafizalzawad/Neural_Network_Notebooks.git


Navigate to the folder:

cd Neural_Network_Notebooks


Open the notebook:

jupyter notebook


OR upload the .ipynb file directly to Google Colab and run all cells.
